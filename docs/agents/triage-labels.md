# Triage labels

Each triage role maps to a label of the same name on this repo.

| Label | Meaning |
|---|---|
| `needs-triage` | The owner has yet to evaluate it |
| `needs-info` | Waiting on the reporter for more information |
| `ready-for-agent` | Fully specified; an agent can implement it unattended |
| `ready-for-human` | Needs the owner to implement it |
| `wontfix` | Will not be actioned |
